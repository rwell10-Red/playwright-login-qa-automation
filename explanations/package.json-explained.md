# package.json — Line by Line Explanation

**File location:** `package.json` (project root)
**Purpose:** The Node.js project manifest. Every Node.js project needs this file. It defines the project name, version, dependencies, and shortcut commands (scripts). npm reads this file to know what packages to install and what commands are available.

---

```json
{
```
**Line 1** — Opens the JSON object. `package.json` is always a single JSON object — everything is inside these outer curly braces.

---

```json
  "name": "week-1-practical",
```
**Line 2** — The project name. npm uses this internally. Must be lowercase with no spaces (hyphens allowed). This becomes the package name if the project were ever published to the npm registry.

---

```json
  "version": "1.0.0",
```
**Line 3** — The project version following Semantic Versioning (semver): `MAJOR.MINOR.PATCH`.
- `1` = major version (breaking changes)
- `0` = minor version (new features, backward compatible)
- `0` = patch version (bug fixes)
- `1.0.0` is the standard starting version for a new project.

---

```json
  "description": "",
```
**Line 4** — A short description of the project. Empty here — would be filled in for a published package. npm search results use this field.

---

```json
  "main": "index.js",
```
**Line 5** — The entry point file if this package were required by another Node.js project. Not relevant for a test-only project — this project has no `index.js`. This field was auto-generated by `npm init -y` and can be ignored.

---

```json
  "scripts": {
    "test": "playwright test",
    "test:desktop": "playwright test --project=chromium-desktop",
    "test:mobile": "playwright test --project=mobile-chrome",
    "test:headed": "playwright test --headed",
    "test:report": "playwright show-report"
  },
```
**Lines 6–12** — npm scripts. These are shortcuts that run full commands by typing `npm run <script-name>`. Think of them as aliases.

| Script | Full Command It Runs | What It Does |
|---|---|---|
| `npm test` | `playwright test` | Runs all 25 tests headlessly |
| `npm run test:desktop` | `playwright test --project=chromium-desktop` | Runs only desktop tests (TC_LOGIN_001–009 + 010 on desktop) |
| `npm run test:mobile` | `playwright test --project=mobile-chrome` | Runs only mobile tests (TC_LOGIN_010 on Pixel 5 viewport) |
| `npm run test:headed` | `playwright test --headed` | Opens a visible browser — you can watch tests run |
| `npm run test:report` | `playwright show-report` | Opens the HTML report in a browser after tests complete |

- `npm test` is a special built-in shortcut — it does not need the `run` keyword
- All others need `npm run` before the script name
- Scripts call `playwright` directly because `@playwright/test` is installed locally in `node_modules/.bin/`

```json
  "keywords": [],
```
**Line 13** — Keywords for npm registry search. Empty array — not relevant for a local project.

---

```json
  "author": "",
```

**Line 14** — Author name. Empty — auto-generated by `npm init -y`. Would contain your name or email for a published package.

---

```json
  "license": "ISC",
```
**Line 15** — The software license. `ISC` is a permissive open-source license similar to MIT. Auto-generated default. Not relevant for a private project.

---

```json
  "type": "commonjs",
```
**Line 16** — Specifies the module system. `"commonjs"` means files use `require()` and `module.exports` syntax (which is what the Playwright test files use: `const { test, expect } = require('@playwright/test')`). The alternative is `"module"` which uses `import`/`export` ES module syntax.

---

```json
  "devDependencies": {
    "@playwright/test": "^1.62.1"
  }
```
**Lines 17–19** — Development dependencies. Packages listed here are only needed for development and testing — they are NOT included when deploying the app to production.
- `"@playwright/test"` — the Playwright test runner package. This is what provides `test()`, `expect()`, `page`, `browser`, and all other Playwright APIs.
- `"^1.62.1"` — the version range:
  - `^` means "compatible with" — npm will install version 1.62.1 or any newer version that does not break compatibility (any 1.x.x where x >= 62.1)
  - The actual installed version is locked in `package-lock.json` (auto-generated by npm)

## How This File Was Created

This file was generated automatically by running:
```powershell
npm init -y
```
The `-y` flag answers "yes" to all prompts and uses defaults. The scripts and devDependencies were then added manually:
```powershell
npm install --save-dev @playwright/test
```
This installed `@playwright/test` and added it to `devDependencies` automatically.
